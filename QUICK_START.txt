🚀 DEPLOY IN 5 MINUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1: GitHub Pages (Recommended)
─────────────────────────────────────

1. Create repo: https://github.com/new
   Name: hocsuperapp (or any name)
   Visibility: Public

2. Clone and upload files:
   git clone https://github.com/YOUR_USERNAME/hocsuperapp.git
   cd hocsuperapp
   cp -r /path/to/hoc-super-app-export/* .
   git add . && git commit -m "Deploy" && git push

3. Enable Pages:
   Go to Settings → Pages
   Source: main branch, / (root)
   Save

4. Your site is live at:
   https://YOUR_USERNAME.github.io/hocsuperapp/


OPTION 2: Netlify (Easiest)
──────────────────────────

1. Go to https://netlify.com
2. Drag & drop the hoc-super-app-export folder
3. Your site is live instantly

Get a custom domain in Netlify settings.


OPTION 3: Vercel
───────────────

1. Go to https://vercel.com
2. Click "Add New..." → "Project"
3. Upload the hoc-super-app-export folder
4. Your site is live instantly


OPTION 4: Your Own Server
─────────────────────────

Copy all files to your web server's public directory:

  scp -r hoc-super-app-export/* user@server:/var/www/html/

Then access at https://your-domain.com

⚙️ LOCAL DEVELOPMENT

Setup:

  pnpm install
  pnpm run dev

  Output: dist/public/
